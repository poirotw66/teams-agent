# Agents Playground 測試情境與範例問題

本文件整理本機 Playground 可測的對話腳本，涵蓋 RAG、FAQ、澄清、Handoff、工單、人工 Demo 等流程。

## 測試前準備

| 項目 | 說明 |
|------|------|
| 入口 | http://127.0.0.1:3979/login（密碼 `local-playground`） |
| 網址 | 請固定使用 `127.0.0.1`，不要混用 `localhost` |
| 新對話 | 每測一個情境最好清掉舊 conversation |
| 回覆時間 | 一輪約 6–15 秒，handoff 可能更久 |
| 知識庫 | 本機索引約 22 chunks，含 VPN、大州、Gitlab、入口網等 |
| 知識後端 | 登入後右上角可切換 **HYBRID** 或 **Gemini File Search** |

---

## 1. 知識庫命中（RAG 正常回答）

應回具體處理方式，並可能附**來源**與 **👍/👎** 回饋。

| 測試句 | 預期 |
|--------|------|
| `VPN 密碼鎖住怎麼辦` | 引用 VPN 相關文件回答 |
| `大州系統功能無法點選` | 大州 IE/安全性設定類答案 |
| `Gitlab 帳號被鎖怎麼解鎖` | Gitlab 解鎖/重置說明 |
| `金控入口網密碼要怎麼變更` | 入口網密碼變更步驟 |
| `樹精靈 AP 無法登入` | AP 登入排查 |
| `XQ 客服電話是多少` | XQ 相關 FAQ |
| `總公司 IP 話機怎麼轉接` | IP 話機操作說明 |
| `國泰 e 點名密碼忘記了` | 員工入口網/CTeam/e點名相關 |

**對照組（File Search）：** 右上角切到 **Gemini File Search**，再問 `VPN 密碼鎖住怎麼辦`，比較回答與來源是否一致。

---

## 2. FAQ 固定答案

目前啟用的 FAQ 主要是**通報格式**（`FAQ_004`）。

| 測試句 | 預期 |
|--------|------|
| `通報資訊問題要寫什麼` | 固定 FAQ：主旨格式、必填欄位、截圖等 |
| `報修信要怎麼寫` | 同上類型的 FAQ 答案 |

---

## 3. 資訊不足 → 追問澄清

| 測試句 | 預期 |
|--------|------|
| `VPN 打不開` | 追問 VPN 名稱、錯誤訊息等 |
| `我的設備無法解鎖` | 追問是哪個系統/應用、有無錯誤碼 |
| 接上一句回：`公發手機` | 依補充資訊繼續處理或進 handoff |

---

## 4. 知識庫查無 → Handoff 摘要

這些**不在索引內**，應走「查無可確認答案」+ **案件摘要** + 四個選項。

| 測試句 | 預期 |
|--------|------|
| `SAP Crystal Reports 授權到期無法開啟` | Handoff 摘要（回歸測試常用） |
| `Outlook 一直閃退無法開啟` | 同上 |
| `印表機無法列印，顯示離線` | 同上 |
| `Windows 更新後藍畫面` | 同上 |
| `SharePoint 文件開不起來` | 同上 |

**Handoff 後續指令（需整句吻合）：**

| 指令 | 預期 |
|------|------|
| `建立派工單` | 依摘要建 Mock 工單，回覆含工單編號 |
| `聯絡線上客服` | 進入 Demo 人工模式 |
| `繼續補充` | 請你補充，重新產生摘要 |
| `取消` | 取消轉接，恢復一般 AI |

---

## 5. 直接要求真人客服

| 步驟 | 測試句 | 預期 |
|------|--------|------|
| 1 | `我要找真人客服` | 直接出案件摘要 + 四個選項 |
| 2 | `聯絡線上客服` | 「已進入真人客服模式（Demo）」 |
| 3 | `我還是連不上 VPN` | 訊息保存至案件，**不**由 AI 自動答 |
| 4 | `/close` | 結束 Demo，恢復 AI |

---

## 6. 建立工單（含確認）

### 路徑 A：Handoff 後建單

1. `SAP Crystal Reports 授權到期無法開啟`
2. `建立派工單`

### 路徑 B：明確開單意圖

| 測試句 | 預期 |
|--------|------|
| `請協助建立派工單` | 走工單流程（可能先摘要/確認） |
| `幫我開派工單，VPN 完全連不上` | 明確建立意圖 |

### 不應建單（有否定/猶豫）

| 測試句 | 預期 |
|--------|------|
| `可能要報修 VPN` | **不**直接建單（含「可能」） |
| `先不要建立派工單` | 取消/不建單 |

| 測試句 | 預期 |
|--------|------|
| `查詢我的工單` | 列出 Mock Ticket 工單 |
| `我的派工單進度如何` | 工單查詢，不走 FAQ/RAG |

---

## 9. 多問題 / 切換情境

| 測試句 | 預期 |
|--------|------|
| `VPN 無法登入，另外 Outlook 也有問題` | 拆成多個 issue 或合併處理 |
| 先問 SAP（handoff 中）再問：`VPN 密碼鎖住怎麼辦` | 新 IT 問題應**取代** pending handoff，VPN 正常 RAG |

---

## 10. 回饋與後端切換

| 步驟 | 目的 |
|------|------|
| 問 `VPN 密碼鎖住怎麼辦` → 按 **👍 已解決** | 測 feedback API |
| 右上角 **HYBRID ↔ Gemini File Search** 切換後重問同一題 | 測 evaluation backend 注入 |

---

## 建議測試順序（約 15 分鐘）

1. `VPN 密碼鎖住怎麼辦` — 確認 RAG 正常
2. `通報資訊問題要寫什麼` — FAQ
3. `VPN 打不開` → 補充細節 — 澄清
4. `SAP Crystal Reports 授權到期無法開啟` → `建立派工單` — Handoff + 工單
5. `我要找真人客服` → `聯絡線上客服` → `/close` — 人工 Demo
6. `查詢我的工單` — 工單查詢
7. 切 **Gemini File Search** 重測第 1 題 — 後端切換
